Epsilon Browser Playground

Programs in Eclipse Epsilon's languages run here in your browser, against JSON and CSV models. The Epsilon engines are Java compiled to JavaScript with TeaVM, so no server or JVM is involved.

    Each run starts from the program and inputs shown, and edits are kept while you switch examples. EOL places statements before operation definitions.
    Parallel operations such as parallelSelect run sequentially, since the page has one thread. Loading models over HTTP, XML features and running native processes are not available.
    Flock needs models that support reflection (such as EMF models), which the JSON and CSV drivers do not, so it has no example here. A program that never terminates will freeze this tab.
